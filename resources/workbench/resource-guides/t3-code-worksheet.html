T3 Code

An open-source interface for running supported coding agents on your own machine, with desktop, web and mobile clients.

Use this with the team

Use when one interface would help manage existing coding-agent workflows. Confirm the supported provider, authentication and project permissions first.

Practical exercise: Pilot one authorized local task, inspect its changes and record the app/provider versions. Add remote access only when the task requires it.

Access: MIT-licensed app; authenticated provider access and compute are separate; provider usage limits apply
