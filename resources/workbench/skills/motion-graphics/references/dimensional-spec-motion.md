# Animated UI dimension sheets

Use only for requested animated specifications/explanations. Begin with a verified ui-dimensional-spec and source-linked values; unknowns stay visible.

Use the existing deterministic workflow: one pure render(t)/seek(t) state and one camera transform over stable geometry. Reveal geometry, dimensions, then labels/table references. Draw strokes before fills when clearer. Avoid independent transforms detaching labels from features.

Select only explanatory views: anatomy, relevant detail, state/breakpoint change and optional exploded layer view. Keep labels readable at delivery resolution with adequate hold time. Review beat stills under the parent workflow's approval gate before video. Prompt-only requests end with prompts.

Check transitions/holds, code/table correspondence, arbitrary seeking, static/reduced-motion alternatives for interactive delivery and final export legibility. Use available tooling; this recipe does not authorize Playwright/Chromium/ffmpeg installation.
