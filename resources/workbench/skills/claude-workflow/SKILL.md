# Claude workflow

Start from the user's outcome and the work already available. Keep the operating instructions small; open a supporting reference only when that issue matters.

## Apply during Claude work

- Establish the client, available tools and relevant project instructions before recommending commands. Claude Code, Cowork and web chat have different capabilities.
- Assemble one bounded task with the audience, source material, constraints and a visible completion check. Use [task-brief.md](references/task-brief.md) when the scope is ambiguous. Resolve routine choices from existing context; ask only about consequential gaps.
- Keep implementation context focused. Read relevant files and narrow search results; summarize findings with evidence locations. Use authorized delegation when it adds value, without making helpers a requirement for ordinary work.
- For creative decisions with meaningful alternatives, compare a few distinct directions against the same criteria before expanding the selected one. Skip duplicate drafts when the direction is already established.
- Replace vague emphasis with observable requirements and a reason where it affects judgment. Keep client references and the existing design system above generic style advice.
- When corrections stop producing progress, preserve the verified state and change the approach. Use [handoff.md](references/handoff.md) before a context reset or transition. Never discard ongoing work just to shorten the conversation.
- Keep model and effort choices appropriate to the task, respecting the user's configured choice. Use [usage-and-client-notes.md](references/usage-and-client-notes.md) for cost or setup questions. Treat measured usage and estimated API cost as different data.
- Verify the deliverable using the relevant observable result: a running interaction, evidence-backed analysis, file inspection or necessary tests. Report remaining uncertainty precisely.

For an extension or connector, inspect source, execution, access and rollback using [extension-review.md](references/extension-review.md). A review does not itself authorize installation or new access.

## Portable use

In a client that supports skills, install this folder with its references. In ordinary chat, attach this file and the relevant reference. These instructions do not grant access to files, install integrations, change settings or create recurring activity.
