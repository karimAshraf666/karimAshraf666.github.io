# Agent task brief

Read the current materials and accepted decisions first. Extract the intended outcome, audience, source of truth, constraints and a check that would demonstrate completion. Resolve routine choices from context. For a narrow request that is already clear, proceed directly without adding a document or interview.

For substantial work, produce a brief with:

- Outcome and intended use.
- Sources and existing decisions to preserve.
- Included work and exclusions.
- Important constraints and the reasons behind them.
- Deliverable and observable acceptance checks.
- Material unknowns, explicitly labeled assumptions and next action.

Use the [editable Markdown template](task-brief.md) if a team needs a reusable artifact. Ask only questions whose answers could materially change the solution; use concise choices where helpful. Preparation that does not depend on an answer can continue.

For a visual task, locate the reference and approved assets. Name observable qualities instead of asking for a vague premium or non-AI look. If direction is open, compare a few distinct options under the same criteria, then expand the chosen one.

The brief carries existing authorization; it does not manufacture a new approval gate. Keep factual claims tied to sources, and do not invent audience research, traction or platform capabilities.
